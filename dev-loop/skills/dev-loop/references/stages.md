# 六步定义与 Gate 细则

每步五要素：目标 / 输入 / 产出 / Gate / 兜底。Gate 判定不过 → 补缺口或回退，具体规则见 SKILL.md 失败处理。

## ① 需求

- **目标**：把模糊想法变成对齐过的问题定义、目标用户、成功标准与优先级。
- **输入**：用户口述 / 既有材料；无。
- **产出**：`docs/prd.md`（含问题陈述、目标用户、核心场景、验收标准、非目标）。
- **Gate**：
  1. 问题陈述指向具体人群的具体痛点，不是"做一个 X 平台"；
  2. 有可验收的成功标准（能量化或能演示），不是"用户体验好"；
  3. 非目标明确列出（防止范围蔓延）；
  4. 每条验收标准都可在④被独立验证。
- **兜底**：编排器访谈式补齐四要素后自产 1 页 PRD；用户答不出的字段标注 `⚠️ 待验证`，不得编造。

## ② 设计

- **目标**：把 PRD 转化为可实现、可验收的设计规格，别做艺术孤品。
- **输入**：`docs/prd.md`。
- **产出**：`docs/design.md`（页面清单、每页关键状态、交互要点、导航结构；视觉类产物路径一并索引）。
- **Gate**：
  1. 主流程完整可走通（入口→核心操作→完成）；
  2. 异常态有设计：空 / 加载 / 错误 / 权限 / 边界数据（移动端加离线）；
  3. 每个页面能在③被实现（有结构有布局有状态，不是只有口号）；
  4. 与 PRD 的验收标准一一对应，无遗漏场景。
- **兜底**：编排器按 PRD 场景自产 1 页设计说明，重点是状态覆盖而非视觉细节。

## ③ 实现

- **目标**：按设计规格产出可运行的代码，自验通过。
- **输入**：`docs/design.md` + `docs/prd.md` 验收标准。
- **产出**：`src/`（源码）+ 测试；运行方式写进 README。
- **Gate**：
  1. 核心功能可跑通（能启动、能完成主流程）；
  2. 自验通过：每条 PRD 验收标准都在本地验证过一次，验证方式记录在案；
  3. 无已知 P0（崩溃 / 数据丢失 / 主流程断裂）；
  4. 遵循克制原则：无凭空引入的抽象与依赖。
- **兜底**：主 agent 本就是执行者；无外部 skill 时按 Karpathy 准则手写实现 + 逐条自测。

## ④ 验收

- **目标**：独立验证实现是否符合设计与需求——实现者不能自己给自己盖章。
- **输入**：`src/` + `docs/design.md` + `docs/prd.md` 验收标准。
- **产出**：`docs/qa-report.md`（逐条结论：通过 / 不通过 + 证据）。
- **Gate**：
  1. PRD 每条验收标准都有独立结论与证据（截图 / 复现步骤 / 测试输出）；
  2. 主流程 + 至少一类异常态实测通过；
  3. 发现的问题分级（阻断 / 重要 / 次要），阻断项必须为零才能进⑤；
  4. 不通过项明确指出回退目标（回③修实现 / 回②修设计 / 回①修需求）。
- **兜底**：编排器按 PRD 验收标准逐条人工核对，产出核对表；标注哪些结论来自推理而非实测。

## ⑤ 交付

- **目标**：让没参与开发的人能审查、部署、接手这个项目。
- **输入**：前四步全部产物。
- **产出**：`docs/` 交付集——架构说明、关键流程、权限与环境变量、测试覆盖说明、README（如何运行）。
- **Gate**：
  1. 架构：模块划分 + 依赖方向，一页能看懂；
  2. 流程：用户 / 请求的关键路径有图或文字链路；
  3. 权限与变量：用到哪些账号体系、环境变量、密钥（只列名，不写值）；
  4. 测试覆盖：哪些验证过、哪些没有，诚实标注。
- **兜底**：编排器扫描代码自产 README + 架构说明；无法从代码推出的部分标注 `⚠️ 待补`。

## ⑥ 复盘

- **目标**：对照当初的判断和实际结果，提炼下一轮要用的经验——这是闭环回流的关键步。
- **输入**：`docs/prd.md` 的成功标准 + 实际结果（数据 / 反馈 / 上线表现）+ 各步决策记录。
- **产出**：`docs/retro.md` → 其中"下一轮需求输入"一节直接作为下一轮①的输入。
- **Gate**：
  1. Expected vs Actual 逐项对比，不只讲成功不讲偏差；
  2. 每个 Gap 有归因（当初判断错 / 执行走样 / 环境变化），不接受"运气不好"；
  3. 产出至少 1 条下一轮可执行的需求输入（做 / 改 / 砍）；
  4. 经验写入状态文件决策记录，供后续轮次引用。
- **兜底**：编排器自产对比表 + 3 条行动项；无实际数据时明确写"数据缺失，仅流程复盘"。
