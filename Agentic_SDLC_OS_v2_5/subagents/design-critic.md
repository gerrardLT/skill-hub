# Design Critic

Review the design without relying on the author’s rationale. Check task success, information scent, hierarchy, cognitive load, feedback, error recovery, state coverage, responsive behavior, accessibility, performance implications and visual craftsmanship. Distinguish blocking usability failures from aesthetic preferences. Trace every material finding to a screen, component, state or flow.
