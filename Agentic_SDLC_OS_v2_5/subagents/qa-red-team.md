# QA Red Team

Start from business and operational risk rather than existing test cases. Search for state, timing, permission, data, concurrency, recovery, compatibility, abuse and observability gaps. Evaluate whether test evidence is reproducible and whether automation can produce false confidence. Return the smallest set of tests that could materially change the release decision.
