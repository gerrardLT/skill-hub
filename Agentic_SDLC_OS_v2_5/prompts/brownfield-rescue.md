# 低质量现有项目救援提示词

```text
使用 Agentic SDLC OS 对当前 brownfield 项目做系统救援。

先建立真实基线，不要直接重写：
- 产品目标、用户和关键旅程
- 信息架构与交互状态
- 架构、模块、依赖、数据和技术债
- 测试覆盖与实际通过证据
- 构建、部署、回滚和环境
- 日志、指标、告警、错误、性能和用户反馈

将发现写入 evidence/risk/artifact/traceability。识别不可补偿门槛和最高杠杆瓶颈，形成按风险与价值排序的修复波次。一次只推进一个可验证波次：设计/技术方案 → 实现 → 独立 QA → 渐进发布 → 线上验证 → 学习。禁止大爆炸重写，除非有证据证明渐进迁移不可行。
```
