# 端到端执行提示词

```text
使用 Agentic SDLC OS 完成当前软件目标的端到端闭环。

不要把“端到端”理解为机械执行所有步骤。先读取 .sdlc 和现有证据，从最早失效或缺失的关键阶段开始；只执行对当前决策有价值的 OS 和 Skills。

必须满足：
- 事实、推断、假设、决策分离；
- 关键制品注册，并形成上游意图到下游验证的有向追踪路径；
- 关键风险不能被平均掉；
- 每次跨 OS 前运行 audit、health 和 Gate；
- Engineering 完成声明必须有新鲜测试/审查证据；
- QA 独立给出残余风险；
- Release 有授权、停止条件、回滚和生产验证；
- Evolution 用真实指标/反馈决定继续、修复、停止或回流。

持续推进到当前权限和证据允许的最远状态。遇到需要人类授权的生产动作、Gate 豁免或重大取舍时停止在明确决策点，不伪造批准。
```
