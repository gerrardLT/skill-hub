# AI 中文搜索工具 PRD（Purified v2 — TC01）

> 生成方式：pr_to_ac_concise v2 方法——单轮直出，执行 OQ 三元组 + 每 P0 故事≥3 AC 其中≥1 异常态规则。

## 📌 Executive Summary

中文用户使用 Perplexity 等英文优先 AI 搜索时，答案质量因语言与信源生态降级。本产品为中文构建答案优先的 AI 搜索：检索中文信源、逐句引用支撑生成、保留信源可溯性。达成后将把查询→可信答案时间从多轮翻页缩短为一次交互。

## ❓ Problem Statement

- **用户**：中文重度搜索用户（学生、研究者、内容创作者、职场人士）
- **痛点**：AI 搜索工具（Perplexity/ChatGPT）以英文语料为主，中文查询出现信源失配、答案模板化、引用缺失
- **证据**：⚠️ Open Question OQ-4 未提供一手调研数据；假设"中文 AI 搜索质量显著低于英文"待验证

## ✅ User Stories & Acceptance Criteria

**P0**

**US-1 带引用的中文答案**
- US-1.1 Given 用户输入中文问题 When 提交查询 Then 流式输出答案中每个事实论断后带编号引用标记 [1][2]
- US-1.2 Given 命中专业中文信源 (如学术站/官方媒体) When 生成 Then 引用列表按信源质量降序排列，高质量信源靠前
- US-1.3 Given 查询无可靠信源 WHEN 生成 THEN 输出明确提示“未找到可靠信源”而非编造（异常态）
- US-1.4 Given 网络中断发生在输出中 WHEN 重试 THEN 已输出部分不丢失并恢复会话继续（异常态）

**P0**

**US-2 引用跳转**
- US-2.1 Given 答案含编号引用 When 点击 When 定位到对应信源卡片并高亮摘录原文
- US-2.2 Given 引用原文被删除 WHEN 跳转 THEN 显示缓存快照并标注“原文已不可达”（异常态）
- US-2.3 Given 加载失败时 WHEN 重试 THEN 3 秒内完成或友好提示等待（异常态）

**P1**

**US-3 追问深挖**
- US-3.1 Given 某条引用存在 WHEN 针对该引用追问 THEN 返回其上下文相关段落并聚焦该信源
- US-3.2 Given 追问超出信源范围 WHEN 回答 THEN 说明边界并请求澄清问题
- US-3.3 Given 会话超时 WHEN 返回 THEN 保持当前信源聚焦状态（异常态）

**P1**

**US-4 信源可信度标签**
- US-4.1 Given 信源卡片渲染 WHEN 加载 THEN 显示域名 + 标题 + 可信度标签四档之一（官方/专业媒体/社区/未验证）
- US-4.2 Given 新信源首次出现 WHEN 评分 THEN 自动评估并分配到正确可信度等级
- US-4.3 Given 标签错误 WHEN 报告 THEN 人工复核并在下次迭代中修正（异常态）

**P1**

**US-5 空状态处理**
- US-5.1 Given 无任何结果 WHEN 展示 THEN 呈现友好空状态文案与引导建议而非留白（异常态）
- US-5.2 Given 搜索框为空 WHEN 焦点离开 THEN 不触发默认搜索行为而是显示占位符文案
- US-5.3 Given 历史清空 WHEN 执行 THEN 保留最小界面框架避免布局抖动（异常态）
