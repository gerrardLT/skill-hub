# AI 中文搜索工具 PRD（Purified v3 — TC01）

## 📌 Executive Summary

中文用户使用 Perplexity 等英文优先 AI 搜索时，答案质量因语言与信源生态降级。本产品为中文构建答案优先的 AI 搜索：检索中文信源、逐句引用支撑生成、保留信源可溯性。达成后将把查询→可信答案时间从多轮翻页缩短为一次交互。

## ❓ Problem Statement

- **用户**：中文重度搜索用户（学生、研究者、内容创作者、职场人士）
- **痛点**：AI 搜索工具（Perplexity/ChatGPT）以英文语料为主，中文查询出现信源失配、答案模板化、引用缺失
- **证据**：⚠️ OQ-5 未提供一手调研数据；假设"中文 AI 搜索质量显著低于英文"待验证

## ✅ User Stories & Acceptance Criteria

**P0**

**US-1 带引用的中文答案**
- AC-1.1 Given 用户提交中文问题 When 系统检索到信源 Then 流式输出答案中每个事实论断后带编号引用 [1][2]
- AC-1.2 Given 命中专业中文信源 (学术站/官方媒体) When 排序 Then 引用列表按信源质量降序排列，高质量靠前
- AC-1.3 Given 无可靠信源匹配 WHEN 生成 THEN 明确提示“未找到可靠信源”而非编造答案（异常态）

**P0**

**US-2 引用跳转**
- AC-2.1 Given 答案含编号引用 When 点击引用 Then 页面滚动到对应信源卡片并高亮原文摘录
- AC-2.2 Given 引用原文已失效 WHEN 跳转 THEN 显示缓存快照并标注“原文不可达”（异常态）

**P0**

**US-3 诚实性与容错**
- AC-3.1 Given 网络中断发生在输出中 WHEN 重试 THEN 已输出部分不丢失且会话可恢复继续（异常态）
- AC-3.2 Given 无内容农场可引用 WHEN 回答 THEN 避免使用单一低质信源作为唯一依据（异常态）

**P1**

**US-4 追问深挖**
- AC-4.1 Given 某条引用存在 WHEN 针对该引用追问 THEN 返回其上下文相关段落并聚焦该信源

**P1**

**US-5 空状态处理**
- AC-5.1 Given 查询无任何结果 WHEN 展示 THEN 呈现友好空状态文案与引导建议而非留白（异常态）

## 🚫 Out of Scope

- **生成式写作助手功能**——不是搜索 MVP 范围，延后至 Phase2
- **移动原生 App**——先验证 Web 需求，后续用 React Native
- **用户账号体系与历史同步**——MVP 用本地会话存储，延迟至有需求
- **英文专门优化**——专注中文，英文仅自然兼容不单独投资
