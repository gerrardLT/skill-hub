# Status: Needs Input

A requirements and acceptance-criteria contract cannot be drafted without defining what decisions the dashboard must support and how its data will be measured. Please provide only these minimum inputs:

| Missing input | Minimum question | Owner |
|---|---|---|
| Target users | Who will use the dashboard to make a decision? | Unknown; leadership should identify the accountable user group |
| Decision and deadline | What specific decision must the dashboard support, and by when? | Unknown; leadership should name the decision owner |
| Event definitions | Which tracked events represent the behavior needed for that decision, including exact inclusion/exclusion rules and time windows? | Unknown; data owner required |
| Data owner | Who owns and can validate the source data and event definitions? | Unknown |
| Baseline | What is the validated current value for each approved metric and measurement period? | Unknown; data owner to validate once identified |
| Target | What outcome or threshold is required, over what period? | Unknown; decision owner to set after the baseline is validated |

Until these inputs are supplied, metric definitions, personas, targets, alert thresholds, dashboard layout, and acceptance criteria remain intentionally unspecified. No dashboard success, validated demand, or approved metric definitions are claimed.
